PROJECT OVERVIEW

Overview Project Sistem Ticketing

Perancangan sistem ticketing berbasis web untuk mendukung pencatatan, pengelolaan, dan pemantauan permintaan layanan secara lebih terstruktur.

Problem

Proses pelaporan kendala dan penanganan request layanan IT di lingkungan PMI Kota Semarang sebelumnya belum terstruktur dengan baik dan sering kali tidak terdokumentasi secara formal. Hal ini menyulitkan tim IT dalam melacak riwayat permasalahan teknis, menentukan prioritas penanganan kendala, serta mengelola efisiensi pelaporan operasional harian.

Solution

Merancang dan membangun prototype UI/UX beserta simulasi alur backend untuk sistem informasi Ticketing Request Layanan IT berbasis website. Sistem ini didesain khusus untuk mendigitalisasi alur pengajuan bantuan teknis, memungkinkan staf internal memasukkan laporan kendala secara sistematis, serta memberikan dasbor pengelolaan bagi tim IT untuk memperbarui status pengerjaan.

Hasil

Terciptanya sebuah platform digital terpusat yang berhasil mempermudah dan merapikan tata kelola kerja staf IT. Kini, seluruh dokumentasi pelaporan request layanan IT menjadi jauh lebih terstruktur, meminimalkan risiko adanya aduan yang terlewat, dan mempermudah tim IT dalam meninjau kembali riwayat pemeliharaan infrastruktur teknologi di PMI Kota Semarang.
